# **¿Cuál es la diferencia entre MariaDB y MySQL?**

MariaDB es un fork(clon) de MySQL, lo que significa que es una versión de MySQL que se ha desarrollado a partir de su código fuente original. La principal diferencia entre MariaDB y MySQL es que **MariaDB es de código abierto y MySQL es propiedad de Oracle Corporation y tiene una licencia comercial**.

- De todos modos ambos son sistemas de gestión de bases de datos relacionales (RDBMS) que utilizan el lenguaje de consulta estructurado (SQL) para realizar consultas y manipular datos.

## *Ventajas de `MariaDB` por sobre `MySQL`*

- Es mucho **más eficiente.**

- **Soporte muchos motores de almacenamiento diferentes.**

- Ofrece un **mejor rendimiento.**

- Es muy **similar a MySQL.**
